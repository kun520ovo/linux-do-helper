# linux.do 助手

这是一个适用于 Linux.do 的浏览器用户脚本，提供自动阅读、智能点赞、账号数据查询和一些页面辅助功能。
## 一句话了解

安装脚本后，打开 Linux.do，点击右下角的礼物图标即可打开助手面板。你可以在面板中开始或停止自动阅读，也可以查看账号、积分和排行榜信息。

## 支持的网站

- `linux.do`：完整功能。
- `idcflare.com`：自动阅读、智能点赞和部分账号功能。
- `cdk.linux.do`：用于读取 CDK 数据，通常不需要手动操作。

## 安装

1. 在 Chrome、Edge、Firefox 等浏览器中安装 [ScriptCat](https://scriptcat.org/) 或 Tampermonkey。
2. 打开 [脚本发布页](https://scriptcat.org/zh-CN/script-show-page/8000)，按页面提示安装。
3. 登录 `linux.do` 后刷新页面。
4. 页面右下角出现“Linux.do 助手”图标，就表示脚本已经加载。

## 快速开始

1. 打开 `https://linux.do/`，点击右下角的礼物图标。
2. 展开“自动阅读”，先按需要调整开关。
3. 点击“开始阅读”。运行中的按钮会变成“停止阅读”，再次点击即可停止。
4. 首次开始时，脚本可能会自动打开一篇指定帖子完成初始化，这是正常现象。

面板可以用鼠标拖动，位置会自动保存；点击右上角的 `×` 或按 `Esc` 可以收起面板。

## 主要功能

### 自动阅读

- 获取“最新帖子”或“未读帖子”。
- 自动打开帖子、滚动阅读并切换到下一篇。
- 可跳过已经读过的帖子，也可以打乱阅读顺序。
- 可选择“完整阅读”，从帖子开头滚动到末尾后再切换。
- 显示本次阅读数、今日阅读数、剩余帖子等状态。

### 智能点赞

开启后，自动阅读过程中会按一定概率给符合条件的帖子点赞，并记录已点赞帖子，避免重复操作。支持慢速、正常、快速三种速度。

智能点赞默认关闭。脚本会检查板块、每日点赞额度和冷却状态；遇到限流或额度用完时会暂停点赞。建议先单独使用自动阅读，确认正常后再开启此功能。

### 账号与数据

展开“账号与数据”后，可以按需查看：

- **账号信息**：信任等级及升级条件、进度。
- **Credit 积分**：可用积分、额度、收支和近几天统计。需要先登录 `credit.linux.do`。
- **CDK 分数**：CDK 分数、信任等级和最近领取记录。需要先登录 `cdk.linux.do`。
- **排行榜**：日榜、周榜、月榜、季榜、年榜和总榜。

这些数据是展开对应栏目后才加载的，加载失败时可以点击刷新。

### 页面辅助

- 在帖子作者旁显示注册天数、发帖/回帖数和信任等级；其他帖子可点击 `📊` 查询。
- 在作者旁提供“查看话题”链接。
- 在帖子列表显示创建时间，并可按帖龄高亮。
- 在帖子中显示楼层号。
- 提供“清爽模式”和“黑白灰模式”。
- 在 Linux.do 上检测到 Cloudflare 验证问题时，可自动或手动打开验证页面。

## 常用设置

设置位于“自动阅读”或“插件设置”中，常用项目如下：

| 设置 | 作用 | 默认值 |
| --- | --- | --- |
| 智能点赞 | 阅读时尝试给符合条件的帖子点赞 | 关闭 |
| 点赞速度 | 慢速、正常、快速 | 正常 |
| 读取未读 | 优先读取未读帖子 | 关闭 |
| 跳过已读 | 不重复打开已读帖子 | 开启 |
| 随机顺序 | 打乱帖子阅读顺序 | 关闭 |
| 完整阅读 | 滚动到帖子底部后再切换 | 关闭 |
| 获取数量 | 每次准备的帖子数量，范围 10～500 | 100 |
| 休息时间 | 连续阅读约 1 小时后的休息时间，范围 1～30 分钟 | 10 分钟 |
| 阅读限制 | 读满指定数量后自动停止 | 关闭 |
| 点赞停止 | 点赞额度用完后停止阅读 | 关闭 |

“创建时间标签”和“帖龄高亮”位于“插件设置”中；Cloudflare 相关选项只在 Linux.do 上显示。

## 常见问题

### 看不到助手面板怎么办？

确认当前网址是 `linux.do` 或 `idcflare.com`，并检查 ScriptCat/Tampermonkey 是否已启用脚本。然后刷新页面，必要时重新打开浏览器扩展。

### Credit 或 CDK 显示未登录怎么办？

分别打开 `credit.linux.do` 或 `cdk.linux.do` 完成登录，再回到 Linux.do 展开对应栏目并点击刷新。CDK 被 Cloudflare 拦截时，先直接访问一次 `cdk.linux.do` 再重试。

### 为什么自动阅读会停止？

达到阅读数量、点赞额度用完、服务器暂时繁忙、页面加载超时或检测到 IP 限流时，脚本可能会主动停止。IP 限流通常会等待约 30 分钟，解除后可以重新点击“开始阅读”。

### 智能点赞没有动作怎么办？

检查是否已经开启智能点赞并正在自动阅读。当前板块不在脚本允许范围、已经点赞过、达到额度或处于冷却状态时，脚本会跳过点赞。

## 注意事项

- 脚本依赖 Linux.do 及相关站点的页面和接口，网站改版后部分功能可能暂时失效。
- 自动化操作可能触发网站限流，请按社区规则使用，并控制运行时间和频率。
- 设置、阅读记录、点赞记录和部分缓存保存在浏览器的脚本存储中；更换浏览器或清理扩展数据后可能需要重新设置。
- 账号信息和积分数据只会在你打开对应功能时请求，显示结果以网站实际返回为准。

## 源码与自动构建

模块化源码位于 `src/`，入口是 `src/entry.js`，用户脚本元数据位于 `src/userscript-header.txt`。

推送代码、提交 Pull Request 或手动运行 [Build userscript](https://github.com/kun520ovo/linux-do-helper/actions/workflows/build.yml) 时，GitHub Actions 会使用 Node.js 22 和 esbuild 0.28.2 打包源码、内联 CSS、添加用户脚本元数据，并检查生成脚本的 JavaScript 语法。
